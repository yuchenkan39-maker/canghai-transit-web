# 沧海出行 · canghai-transit-web

面向留学生的独立网页版公交地图，保留角色图片、天气、汇率和隐藏作者彩蛋。线上地址：https://yuchenkan39-maker.github.io/canghai-transit-web/

## 功能

- Rapid KL 公交线路目录、搜索、多选、常用四线与实时车辆地图。目录当前含 137 条 rapid-bus-kl 类别线路。
- 当前位置与精度圈；最近三个所选线路站点可切换，区分马路两侧的站点编号。
- 到站参考范围：沿线路径、历史同方向／时段路段速度、本车近期速度和前方同向公交共同估算。
- 历史来自 KRI 公开的 2026 年 4 月轨迹，81 条线路有合格样本；显示覆盖比例和来源月份，缺失则回退。站点附近的停车车辆不作为前方堵车证据。
- 同向公交连续偏慢时显示“疑似拥堵或停站”；这是轨迹推断，未接入商业道路路况。
- 天气、令吉兑人民币换算、个人作者彩蛋。

## 数据与限制

实时车辆沿用 Rapid Bus Socket.IO / Engine.IO 3 接入，按 GPS 时间过滤。少量线路约 5 秒一轮；全网分批轮询，一轮约 48 秒。没有车不等于停运，接收时间不等于 GPS 更新时间。

GTFS Static 由构建流程从 data.gov.my 生成线路几何和站点。MRT feeder 静态目录虽已生成，但其另一套实时编号尚未接入；轻轨实时位置也不在当前支持范围。

历史轨迹只在构建临时目录处理，网站发布按路段汇总的速度、样本数、日期数和车辆数。详情、重建流程和留出诊断见 [HISTORY.md](HISTORY.md)。历史数据较旧、未区分公共假日，当前预测范围尚未经过完整行程校准。

持续停车或低速、方向不明、GPS 超过 90 秒时不报行驶分钟数。无匹配历史、无前方车辆时明确回退。最近站点距离是直线距离，不代表可安全步行路线。

只有点击定位功能才申请权限。用户位置用于浏览器本地站点计算，不上传到项目服务器。第三方地图瓦片及天气、汇率请求由浏览器直接访问对应服务。

## 验证

`node --test test/*.test.mjs`：16 项测试覆盖协议、过期消息、路线数据、方向／过站排除、历史数据门槛、时段、前方车辆匹配与局部速度修正。浏览器验证上线入口及数据加载；真实手机位置授权后的实地到站误差仍需继续验证。

## 部署

`.github/workflows/pages.yml` 每次推送 main 后生成最新 GTFS Static、运行测试并部署 GitHub Pages。历史文件已经汇总入库，常规部署不下载原始大文件。

`.github/workflows/history-build.yml` 在历史构建脚本变更或手动触发时重建历史文件，产出审阅用 artifact；通过检查后再更新入库数据。无需付费路况 API Key。
